WINDOWS · BATCH · PYINSTALLER

Python to EXE
Converter

Script interactivo de Windows Batch para localizar archivos Python y empaquetarlos como ejecutables mediante PyInstaller.

01 / DISCOVERY

Buscar scripts

Localiza archivos .py en Desktop, Documents y Downloads o permite introducir una ruta personalizada.

02 / BUILD

Configurar compilación

Comprueba Python y PyInstaller, ofrece opciones de compilación y organiza los resultados en una carpeta de salida.

03 / OUTPUT

Evitar sobrescrituras

Genera nombres incrementales para conservar ejecutables existentes y mantiene los temporales dentro de la carpeta de salida.

Aplicación Windows, no demo web.

La interfaz requiere CMD o el Explorador de archivos de Windows. GitHub Pages presenta la herramienta, pero no ejecuta archivos Batch ni compila binarios.

Uso

Ejecuta Python2Exe_Converter.bat en Windows y sigue el menú. Requiere Python en PATH y puede instalar PyInstaller desde requirements.txt.
